pixelator.pna.analysis_engine.AnalysisManager
=============================================

.. py:class:: pixelator.pna.analysis_engine.AnalysisManager(analysis_to_run: Iterable[PerComponentTask], logging_setup: LoggingSetup | None = None, n_cores: int | None = None, pxl_dataset_builder: Callable[[Iterable[pixelator.pna.pixeldataset.io.PxlFile]], pixelator.pna.pixeldataset.PNAPixelDataset] | None = None)

   Analysis manager that can run a number of analysis across a stream of components.

   The analysis manager is responsible for hooking up the analysis functions and making
   them run on each component in the stream. The main workflow it uses is outlined in the
   `execute` method.

   Initialize the analysis manager.

   :param analysis_to_run: The analysis to run on each component.
   :param logging_setup: The logging setup to use.
   :param n_cores: The number of cores to use for parallel processing (set to 1 to disable
                   parallel processing).
   :param pxl_dataset_builder: A function that can build a PixelDataset from an iterable of
                               PxlFiles.
